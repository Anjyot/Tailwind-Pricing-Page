# 💰 Tailwind Pricing Page

This project is a **modern pricing page built using Tailwind CSS**.

---

## 📌 Features

* 3 pricing plans (Basic, Pro, Premium)
* Modern card UI
* Hover animations
* Highlighted popular plan
